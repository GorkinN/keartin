# Обзор проекта

**Состояние репозитория (2026-09-21):** этап 4 выполнен и принят — SSE-пайплайн поста в FastAPI (RAG → текст → image prompt → Flux). Следующий этап — [05-nestjs.md](stages/05-nestjs.md).

## Цель

Приложение генерирует посты для соцсетей на русском языке:

1. Пользователь загружает материалы (книги, статьи) в форматах PDF, EPUB, FB2, DOCX, TXT (русский и английский).
2. Материалы индексируются в векторную БД (RAG).
3. Пользователь задаёт тему поста, тон, длину, эмодзи, структуру (хуки / тело / CTA), режим источника знаний и пресет стиля.
4. LLM генерирует текст поста, опираясь на RAG-контекст (или общие знания — настраивается).
5. На основе текста LLM формирует промпт для картинки.
6. Flux.1-dev генерирует картинку.
7. Пост (текст + картинка + метаданные) сохраняется в локальную папку и в БД.
8. Публикацию пользователь делает сам (вручную). Редактор разметки поста не нужен — только просмотр результата.

## Критическое ограничение по GPU

Во время генерации изображения Flux.1-dev все остальные модели (LLM в Ollama, embedding-модель, если она на GPU) должны быть выгружены из VRAM.

Это реализуется как **GpuManager** в Python-сервисе, а не как разовые вызовы `ollama stop` из разных мест. См. [01-architecture.md](01-architecture.md).

## Логика генерации поста

- Режим источника знаний: `rag` / `rag_plus` / `general`.
- Цитируемость: отдельная опция, по умолчанию выкл.
- Структура: хуки, тело, CTA — каждый блок можно включить/выключить.
- Параметры: тема, тон, длина, эмодзи (вкл/выкл).
- Стили: пресеты CRUD. Пресет = описание стиля + опционально few-shot примеры.
- Повторная генерация картинки — без перегенерации текста.
- Повторная генерация текста — отдельно.

## RAG

- Форматы: PDF, EPUB, FB2, DOCX, TXT.
- Большие книги (100+ страниц): чанкинг с перекрытием.
- Чанкинг: ~500–800 токенов, overlap ~100.
- Retrieval: top-K 8–12 с фильтром по выбранным источникам.
- Переиндексация при добавлении/замене материала.
- Мультиязычность RU + EN.

## Хранение

**Вариант A (дефолт):** локальные папки.

```
data/posts/2026-09-20_slug-temy/
  post.md
  post.txt
  image.png
  image_prompt.txt
  meta.json
data/library/<book-id>/
  source.pdf
  meta.json
```

**Вариант B:** S3-совместимое хранилище (MinIO в Docker).

В SQLite: полный текст поста, ссылка на картинку (путь или S3-key), метаданные (тема, тон, длина, режим, пресет, seed картинки, модели, дата, ссылки на источники).

Механизм хранения — абстракция `StorageProvider`.

## UI (минимум экранов)

1. **Библиотека материалов** — загрузка, список, статус индексации, удаление, переиндексация.
2. **Создание поста** — источники → параметры → стриминг текста → прогресс картинки → превью → сохранение → повторная генерация текста/картинки.
3. **История постов** — список, просмотр, открытие папки, удаление.
4. **Пресеты стилей** — CRUD.

Редактор разметки поста не нужен.
