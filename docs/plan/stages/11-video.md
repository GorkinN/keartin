# Этап 11. Короткое видео из картинки поста

**Статус:** не начат  
**Зависимости:** [этап 10](10-music.md) принят  
**Следующий этап:** нет, пока эти четыре фичи не закрыты

Код пишется только после отдельного OK.

## Цель

Оживить уже готовую картинку поста. Отдельный генератор роликов из текста не делаем: на RTX 4070 12 ГБ текст-в-видео даёт несколько секунд в низком разрешении и минуты счёта.

## Что делается

- Отдельная кнопка на готовом посте, у которого уже есть картинка. В основной пайплайн шаг не входит.
- Image-to-video: короткий mp4, ориентир 480p и 2–4 секунды.
- Тот же приём, что у Qwen-Image в [docs/GPU.md](../../GPU.md): отдельный процесс, свой тенант (ориентир `video`). Пока процесс считает, остальные модели выгружены. После выхода процесса GpuManager ждёт свободную VRAM.
- Файл `clip.mp4` рядом с `image.png`. Повтор видео не трогает текст, картинку, озвучку и музыкальный фон.
- ComfyUI не подключаем.

## Решения этапа

- Конкретную модель и отдельное venv, если зависимости конфликтуют с основным, фиксирует микро-план перед стартом.
- Веса только из `HF_HOME` / `HUGGINGFACE_HUB_CACHE` / `TRANSFORMERS_CACHE` в `.env`. Путь кэша не хардкодим. Переменные выставляются до импорта библиотек Hugging Face.

## Критерий приёмки

Из готовой картинки получается короткий mp4, его можно открыть из UI. Два видео сразу не считаются. После прогона VRAM свободна, `ollama ps` пуст.
