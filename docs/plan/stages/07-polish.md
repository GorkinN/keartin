**Статус:** выполнен (2026-09-24), ждёт приёмки

**Следующий:** стабильная v1, новые фичи только по отдельному запросу

## Отчёт

### Сделано

- `POST /generate/posts/:id/cancel` и внутренний `POST /pipeline/jobs/:id/cancel`. Во время текста стрим Ollama закрывается, Flux не стартует. Если Flux уже считает, прогон доходит до конца, PNG в пост не пишется, SSE `cancelled`, джоба `cancelled`. Черновик становится `failed`, готовый пост остаётся `ready`.
- `GET /gpu/status` на Nest. Кнопки генерации выключены, пока GPU `locked`, подпись «GPU занят: llm/flux». Отдельного `409` на занятый GPU нет.
- Русские сообщения: Ollama, VRAM, пустой RAG, битый файл, запись в storage. Логи Python и Nest — JSON в stdout.
- Описание пресета от 10 символов. Seed в истории копируется; на создании и на повторе картинки его можно задать.
- Кнопка «Отменить» на мастере и в истории.

### Как проверить

Нужны Vite `:5173`, Nest `:3000`, FastAPI `:8000`, Qdrant, Ollama.

1. Пресет короче 10 символов не сохраняется. `POST /presets` с пустым `description` → `400`.
2. Генерация: токены, прогресс, превью. Пока GPU занят, кнопка на другой вкладке выключена.
3. Отмена на тексте: джоба `cancelled`, Flux не стартует.
4. Отмена на картинке: шаги до конца, новый PNG в пост не попадает, затем `GET /gpu/status` → `locked: false`.
5. Повтор картинки с seed возвращает тот же seed; без seed — другой. Текст тот же.
6. Выключенная Ollama даёт «Ollama недоступна. Запустите её и повторите.»

Чеклист v1 (большая книга, удаление, `ollama ps` после картинки, MinIO через env) на этом прогоне в браузере не гонялся: сервисы для полного GPU-прохода здесь не поднимались. Юнит-тесты Python — 25 passed. `tsc` backend и frontend — без ошибок.

### Не вошло

Авторизация, Redis, toasts, interrupt Flux, `409` на занятый GPU, смена дефолтного стораджа, редактор поста.

## Цель

Поведение «как продукт», без новых подсистем. Закрыть UX, ошибки, логирование, краевые случаи GPU.

## Что делается

- CRUD пресетов довести: валидация описания и few-shot, пустой пресет нельзя сохранить криво.
- Отмена job: abort Ollama stream; если Flux ещё не стартовал — не стартовать; если стартовал — политика «дождаться и пометить cancelled» или аккуратный interrupt, зафиксировать в ARCHITECTURE.
- Человекочитаемые ошибки:
  - Ollama недоступна
  - VRAM не освободилась
  - пустой RAG в режиме `rag`
  - битый файл книги
  - MinIO/FS недоступен
- Структурные логи Python и Nest.
- UX: кнопки disable, пока `GET /gpu/status` busy.
- Seed картинки в UI (показать / скопировать / задать при regenerate).
- Два параллельных generate: второй ждёт или 409 — одно поведение, описать в UI.
- Дописать `docs/ARCHITECTURE.md`, `docs/GPU.md`, `docs/RAG.md` по факту кода.
- Обновить статус в [README плана](../README.md).
