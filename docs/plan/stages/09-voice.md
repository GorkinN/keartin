# Этап 9. Озвучка поста

**Статус:** не начат  
**Зависимости:** [этап 8](08-topics.md) принят  
**Следующий этап:** [10-music.md](10-music.md)

Код пишется только после отдельного OK. Музыку и видео сюда не берём.

## Цель

Голосовая дорожка готового поста для соцсетей. Это озвучка текста, не музыка.

## Что делается

- Кнопка «Озвучить» на готовом посте. В обязательный пайплайн (RAG → текст → картинка) шаг не входит.
- Русский TTS на CPU. Лок GpuManager не берётся, Flux и Ollama не выгружаются.
- Файл `voice.wav` лежит рядом с `post.md` и `image.png`. Ключ в SQLite такой же по смыслу, как у картинки.
- Повтор озвучки перезаписывает только звук. Текст и картинка остаются.
- Текст поста наружу не отправляется. Облачный синтез (в том числе edge-tts) не используем.

## Решения этапа

- Класс модели — локальный русский TTS на CPU (ориентир: Silero или аналог). Конкретную модель фиксирует микро-план перед стартом.
- Зависимости — в `ai-service/pyproject.toml`, без `requirements.txt`.

## Критерий приёмки

У готового поста появляется `voice.wav`, его можно прослушать из UI. Повтор не меняет текст и картинку. `GET /gpu/status` во время озвучки не показывает новый тенант.
